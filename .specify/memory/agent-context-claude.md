# Agent Context: Document Ingestion and Vector Storage System & RAG Retrieval Validation & AI Agent

## Project Overview
- Feature 1: Document Ingestion and Vector Storage System
  - Purpose: Backend pipeline for crawling Docusaurus URLs, extracting and cleaning text content, chunking text, generating embeddings using Cohere models, and storing embeddings in Qdrant Cloud
  - Branch: 001-book-embeddings
- Feature 2: RAG Retrieval Validation System
  - Purpose: Validates that stored embeddings in Qdrant can be properly retrieved with relevant results matching source metadata
  - Branch: 002-rag-retrieval-validation
- Feature 3: AI Agent with Retrieval-Augmented Capabilities
  - Purpose: OpenAI agent that orchestrates retrieval from Qdrant using tool-based approach, answering questions strictly from retrieved content chunks
  - Branch: 001-ai-agent-rag

## Technology Stack
- Python 3.11+: Backend processing language
- Requests: HTTP client for URL fetching
- BeautifulSoup4: HTML parsing and cleaning
- Cohere Python SDK: Embedding generation service (for both document and query embeddings)
- Qdrant Python client: Vector database storage and retrieval
- python-dotenv: Environment variable management
- argparse: Command-line interface parsing
- OpenAI Python SDK: AI agent orchestration and LLM interaction

## Key Components
1. URL Fetcher Module: Retrieves content from Docusaurus URLs with error handling
2. HTML Cleaner Module: Extracts relevant text content and removes UI elements
3. Text Chunker Module: Splits content into appropriately sized chunks (512 tokens max)
4. Embedding Generator Module: Creates vector embeddings using Cohere Python SDK
5. Vector Storage Module: Stores embeddings in Qdrant Cloud with metadata
6. Pipeline Orchestrator: Main function coordinating all modules
7. Query Embedder: Converts user queries to embeddings using Cohere
8. Result Validator: Validates retrieved results against source URLs and metadata
9. Validation Reporter: Generates reports on retrieval accuracy and system health
10. OpenAI Agent: Orchestrates retrieval and response generation using tool-based approach
11. Retrieval Tool: Function that queries Qdrant for relevant content chunks based on user queries
12. Agent Response Formatter: Formats retrieved content into coherent responses for users

## Configuration
- Environment variables for API keys and settings
- CHUNK_SIZE: Maximum size of text chunks (default: 512)
- CHUNK_OVERLAP: Overlap between consecutive chunks (default: 50)
- REQUEST_TIMEOUT: HTTP request timeout (default: 30s)
- MAX_RETRIES: Maximum retry attempts (default: 3)
- QDRANT_COLLECTION_NAME: Name of the collection to search (default: "document_embeddings")
- DEFAULT_TOP_K: Default number of results to retrieve (default: 5)
- SIMILARITY_THRESHOLD: Minimum similarity score for valid results (default: 0.5)

## Data Models
- Document: Represents source documents with URL, title, content
- Text Chunk: Segments of processed text with position tracking
- Embedding: 1024-dimensional vectors with metadata for search
- Query: Represents user search queries with text and embedding
- Retrieval Result: Contains matched content, similarity scores, and source metadata
- Validation Report: Summarizes validation results and system performance
- Agent Response: Final response generated by the agent based on retrieved content
- Conversation Context: Maintains context across multiple interactions
- Tool Parameters: Input parameters for the retrieval tool function

## API Contracts
- /ingest: POST endpoint for URL ingestion
- /search: POST endpoint for vector similarity search
- /status: GET endpoint for system status
- Validation API: Interface for validating retrieval accuracy

## Best Practices Applied
- Circuit breaker pattern with exponential backoff for resilience
- Comprehensive logging for debugging and monitoring
- Validation of data at each processing stage
- Rate limiting handling for external APIs
- Semantic coherence preservation in text chunking
- Query embedding validation for retrieval accuracy
- Source URL and metadata verification for result validation
- Tool-based orchestration for agent functionality
- Strict adherence to retrieved content for response generation (no hallucination)
- Conversational context management for follow-up queries
- Proper error handling for AI service interactions
